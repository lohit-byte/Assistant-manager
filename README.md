⚔️ Monster Legends Team Manager Bot & Dashboard
 
A unified Discord bot and web dashboard designed for Monster Legends alliances to manage Wars, Races, and Maze Islands. Built as a SaaS platform with premium features unlocked via server subscriptions.
 
✨ Features
 
⚔️ War Tracker
• Dynamic 48-hour phase timers (Defense & Attack) managed via Discord commands.
• Missing attack lists with alias mapping (no accidental @mentions).
• Staff approval workflows for player self-logging.
• Warning system with DM notifications. 
🏁 Race Tracker
• Full node tracking (OFA, DYP, JE).
• Built-in OCR to read race screenshots automatically.
• Dynamic team lap targets.
• Staff override capabilities for contributions. 
🗺️ Maze Island
• In-game clock syncing for accurate timers.
• Automated discount pings (10%, 20%, 30%).
• Manual ping overrides via Discord (!maze ping) or the Web Dashboard.
• Player-level opt-in/opt-out ping preferences. 
📊 Web Dashboard
• Discord OAuth2 Login & Server Selection.
• 7-Day Free Trial system with Stripe subscription integration.
• Dropdown-based server configuration (Channels & Roles).
• Alias management (Player self-service + Staff override).
• Local timezone conversion for Maze discounts. 
🛠️ Tech Stack
• Discord Bot: Python (discord.py)
• Dashboard Frontend: Next.js (React) + Tailwind CSS
• Backend & Database: Supabase (PostgreSQL, Auth, Realtime)
• Hosting: Wispbyte (Bot) / Vercel (Dashboard)
